# YURTA.safe — AI-анализатор договоров аренды жилья

> *Статус проекта: MVP*

**YURTA.safe** — это юридическая AI-платформа, созданная для защиты студентов и молодежи Казахстана при найме жилья. Проект автоматизирует анализ юридических документов, подсвечивает критические риски и скрытые уловки в соответствии с законодательством РК (включая ГК РК), гарантируя полную конфиденциальность данных пользователей.

---

**YURTA.safe** позволяет проверить договор аренды за **10 секунд** без участия дорогостоящих юристов. Платформа переводит юридический язык на понятный человеческий и генерирует готовые правовые правки для арендодателей.

### Защита персональных данных и двухэтапная цензура
Безопасность пользователей - ключевой приоритет платформы:
1. **Локальная обезличенность:** На этапе загрузки файл проходит через локальный скрипт анонимизации.
2. **Анонимизация чувствительных данных:** Все личные данные автоматически находятся и заменяются на защищенные маркеры.
3. **Безопасная передача:** Сырые и персональные данные **никогда** не отправляются на внешние серверы или сторонние API вне этого сервиса.

## Технологический стек

### Frontend
* **Vue 3 (JS) + Vite**

### Backend
* **Django / Django REST Framework**

### DBs
* **ChromaDB** - векторное хранилище для сжатия и хранения юридического контекста.

### AI & LLM Infrastructure
* **Qwen2.5 3B Coder Instruct + llama_cpp** - Цензурирование и первичная обработка документа.
* **Groq API** - Главный ИИ-анализ.
* **RAG (Retrieval-Augmented Generation)** - технология для подкрепления и усиления результата.

## Как это работает

1. **Загрузка документа:** Пользователь загружает PDF/PNG файл договора и указывает свою роль в сделке.
2. **Очистка и цензура:** Скрипт маскирует ИИН, ФИО и другие данные на безопасные маркеры.
   * На клиенте: очистка числовых ID (ИИН, телефоны, счета) через регулярные выражения (RegEx)
   * На сервере: Маскировка контекстных сущностей (ФИО, адреса) локальной LLM перед отправкой во внешние API.
3. **Контекстный поиск законодательства** Автоматический подбор релевантных статей Закона РК «О жилищных отношениях» и ГК РК под конкретные условия загруженного договора.
4. **ИИ-Аудит рисков** Сопоставление текста договора с найденными нормами права и глубинная проверка облачной AI-моделью на наличие скрытых ущемляющих условий.
5. **Формирование отчета:** Пользователь получает:
   * Оценку уровня риска и разбор «подводных камней».
   * Ссылки на конкретные статьи ГК РК.
   * Автоматически сгенерированный **Протокол разногласий** (предложения по юридическим правкам).
